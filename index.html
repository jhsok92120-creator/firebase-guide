STEP 1 · 프로젝트 준비

Firebase 프로젝트 설정

홈페이지가 올라갈 원장님 전용 프로젝트(계정 공간)를 만드는 5가지 단계입니다.

⏱ 예상 소요시간 약 15분
📋 총 5단계
귀 병원 홈페이지는 원장님 명의의 Firebase 프로젝트 위에서 제작됩니다. 이렇게 하면 홈페이지 데이터와 계정 소유권이 온전히 원장님께 있으며, 저(개발자)는 편집 권한만 받아 제작·관리를 도와드리는 구조입니다.

STEP 1

Firebase 프로젝트 생성

홈페이지가 올라갈 원장님 전용 프로젝트를 만드는 단계입니다.
1
Firebase 콘솔 접속
구글 계정(가급적 병원용으로 계속 사용하실 계정)으로 로그인한 상태에서 아래 주소에 접속합니다.
https://console.firebase.google.com
2
새 프로젝트 만들기
화면의 "프로젝트 추가"(Add project) 버튼을 클릭합니다.
3
프로젝트 이름 입력
병원 이름이 들어가도록 입력합니다. (예: myclinic-website) 입력하면 아래에 myclinic-a1b2c와 같은 형태로 프로젝트 ID가 자동 생성됩니다.
💡 이 프로젝트 ID는 이후 웹사이트 주소의 일부가 될 수 있으니, 화면에 표시된 ID를 캡처해 두시거나 저에게 전달해 주시면 좋습니다.
4
Google 애널리틱스 설정
"이 프로젝트에 Google 애널리틱스 사용 설정" 항목은 꺼주셔도 무방합니다 (선택 사항이며 나중에 추가 가능).
5
프로젝트 생성 완료
"프로젝트 만들기" 버튼을 누르고 잠시 기다리면 완료됩니다. "계속" 버튼을 눌러 프로젝트 대시보드로 이동합니다.
STEP 2

요금제를 Blaze로 업그레이드

이미지 저장, 실시간 데이터베이스 등 정상 작동을 위해 필요한 단계입니다.
⚠️ "Blaze"는 사용량 기반 종량제 요금제입니다. 병원 홈페이지 수준의 트래픽에서는 대부분 월 0원 ~ 소액 수준이며, 무료 사용량 한도 내에서는 과금되지 않습니다.
1
요금제 변경 메뉴 이동
프로젝트 대시보드 왼쪽 하단의 "업그레이드"(Upgrade) 버튼, 또는 ⚙️ 톱니바퀴 → 사용량 및 결제(Usage and billing)로 이동합니다.
2
Blaze 요금제 선택
"Blaze - 사용한 만큼만 지불" 옵션을 선택하고 "플랜 선택"을 클릭합니다.
3
결제 계정 연결
기존 Google 결제 계정이 있다면 선택하고, 없다면 새로 만들어 카드 정보를 등록합니다.
4
예산 알림 설정 (선택, 권장)
"예산 알림" 금액을 예를 들어 10,000원으로 설정해두면, 초과 시 이메일로 알려줍니다.
STEP 3

Firestore Database 설정

예약 문의, 공지사항 등 데이터를 저장하는 공간을 만드는 단계입니다.
1
Firestore 메뉴 이동
왼쪽 메뉴에서 데이터베이스 및 스토리지를 클릭해 펼친 뒤, "NoSQL" 항목 중 Firestore를 선택합니다.
💡 같은 목록에 "Realtime Database"도 보이는데, 이건 다른 상품이니 헷갈리지 말고 꼭 Firestore를 선택해 주세요.
2
데이터베이스 만들기
"데이터베이스 만들기(Create database)" 버튼을 클릭합니다.
3
위치(리전) 선택
반드시 아래 리전으로 선택해 주세요.
위치: asia-northeast3 (Seoul)
💡 서울 리전을 선택해야 국내 접속 속도가 가장 빠릅니다. 한 번 선택하면 이후 변경이 불가능합니다.
4
보안 규칙 모드 선택
"프로덕션 모드에서 시작(Start in production mode)"을 선택하고 "만들기"를 클릭합니다. 처음부터 외부 접근이 차단된 상태로 시작되며, 이후 제가 필요한 접근 규칙만 안전하게 설정해 드립니다.
STEP 4

Storage 설정

홈페이지에 들어갈 사진, 이미지 파일을 저장하는 공간을 만드는 단계입니다.
1
Storage 메뉴 이동
왼쪽 메뉴에서 데이터베이스 및 스토리지를 클릭해 펼친 뒤, "객체 스토리지" 항목의 Storage를 선택합니다.
2
시작하기
"시작하기(Get started)" 버튼을 클릭합니다.
3
보안 규칙 확인
보안 규칙 모드를 고르는 화면이 나오면 "프로덕션 모드"를 선택하고 "다음(Next)"을 클릭합니다. (화면에 따라 이 단계가 없을 수도 있습니다)
4
위치(리전) 선택
Firestore와 동일하게 아래 리전으로 선택합니다.
위치: asia-northeast3 (Seoul)
5
완료
"완료(Done)"를 클릭하면 Storage 설정이 끝납니다.

2
사용자 및 권한 메뉴
상단 탭에서 사용자 및 권한(Users and permissions)을 클릭합니다.
3
구성원 추가
"구성원 추가(Add member)" 버튼을 클릭한 뒤, 아래 이메일을 입력합니다.
jhsok92120@gmail.com
4
역할(권한) 지정

💡 소유자(Owner) 권한은 원장님만 유지하시고, 개발자에게는 편집자(Editor) 권한만 부여하시면 됩니다.

STEP 2 · 주소 연결

도메인 연결

구매하신 도메인을 홈페이지 주소로 실제 연결하는 5가지 단계입니다.

⏱ 예상 소요시간 10분 + 대기 최대 24시간
📋 총 5단계
도메인은 원장님 명의로 직접 구매하셔야 합니다 (결제가 걸린 부분이라 대신 진행이 어렵습니다). 구매 이후 Firebase와 연결하는 작업은 제가 안내해 드리며, 등록업체 로그인 정보를 공유해 주시면 이 단계도 제가 대신 처리해 드릴 수 있습니다.
1
2
3
4

STEP 1

도메인 구매 확인

가비아, 후이즈 등 국내 등록업체에서 원장님 명의로 도메인을 구매합니다.
1
도메인 구매
가비아(gabia.com) 등에서 원하는 도메인 주소를 검색하고 구매를 완료합니다.
2
로그인 정보 확보
등록업체 아이디/비밀번호를 기억해 두세요. DNS 설정 작업 시 필요합니다.
STEP 2

Firebase Hosting에 도메인 추가

Firebase 콘솔에서 연결할 도메인을 등록하는 단계입니다.
1
Hosting 메뉴 이동
Firebase 콘솔 → 왼쪽 메뉴 호스팅 및 서버리스를 클릭해 펼친 뒤 Hosting을 선택합니다.
2
커스텀 도메인 추가
"커스텀 도메인 추가(Add custom domain)" 버튼을 클릭하고, 구매한 도메인 주소를 입력합니다.
STEP 3

소유권 확인 (TXT 레코드)

이 도메인이 정말 원장님 소유인지 확인하는 절차입니다.
1
TXT 레코드 값 복사
Firebase가 화면에 보여주는 TXT 레코드 값을 복사합니다.
2
등록업체 DNS 설정 이동
가비아 등 등록업체 사이트 로그인 → 도메인 관리 → DNS 설정(네임서버 관리)으로 이동합니다.
3
TXT 레코드 추가
복사한 값을 TXT 레코드로 추가하고 저장합니다.
💡 확인까지 몇 분에서 몇 시간이 걸릴 수 있습니다. Firebase 화면에서 "확인 중" 상태가 뜨면 정상입니다.
STEP 4

연결 레코드 등록 (A 레코드)

실제로 도메인이 홈페이지로 연결되도록 만드는 핵심 단계입니다.
1
A 레코드 값 복사
Firebase가 알려주는 IP 주소(A 레코드)를 복사합니다.
2
등록업체 DNS에 A 레코드 추가
같은 DNS 설정 화면에서 A 레코드로 등록합니다.
3
URL 자동연결(포워딩) 기능 끄기
가비아 등에서 "URL 자동연결" 또는 "포워딩" 기능이 켜져 있으면 반드시 꺼주세요.
⚠️ 이 기능이 켜져 있으면 A 레코드와 충돌해서 사이트가 열리지 않을 수 있습니다.
STEP 5

SSL 인증서 발급 대기

보안 연결(https)을 위한 인증서가 자동으로 발급되는 단계입니다.
1
자동 발급 대기
별도로 하실 작업은 없습니다. Firebase가 자동으로 SSL 인증서를 발급합니다.
2
발급 완료 확인
보통 몇 시간에서 최대 24시간 정도 소요됩니다. 이 기간 동안 사이트가 일시적으로 안 열릴 수 있으나 정상적인 과정입니다.
💡 발급이 완료되면 Firebase Hosting 화면에 초록색 "연결됨" 표시가 뜹니다.

STEP 3 · 오시는 길 지도

카카오맵 API 설정

홈페이지에 "오시는 길" 지도를 표시하기 위해 필요한 5가지 단계입니다.

STEP 1

Kakao Developers 가입 · 로그인

카카오맵 API를 사용하려면 개발자 사이트 가입이 필요합니다.
1
사이트 접속
아래 주소로 접속합니다.
https://developers.kakao.com
2
카카오 계정으로 로그인
병원용으로 계속 사용하실 카카오 계정으로 로그인(또는 신규 가입)합니다.
STEP 2

애플리케이션 생성

카카오맵을 사용할 앱(프로젝트)을 하나 만듭니다.
1
내 애플리케이션 이동
상단 메뉴에서 "내 애플리케이션"을 클릭합니다.
2
애플리케이션 추가
"애플리케이션 추가하기" 버튼을 클릭하고, 병원 이름으로 앱 이름을 입력합니다.
STEP 3

카카오맵 사용 설정

2026년 7월부터 바뀐 절차로, 심사 없이 토글만 켜면 됩니다.
1
제품 설정 이동
생성한 앱 클릭 → [제품 설정] → [카카오맵]으로 이동합니다.
2
사용 설정 켜기
"사용 설정" 토글을 켭니다.
💡 개발자 계정에서 처음 활성화한 앱은 무료 쿼터 내에서 바로 사용 가능합니다. 병원마다 별도 카카오 계정을 쓰시는 것을 권장드립니다.
STEP 4

JavaScript 키 확인

홈페이지 코드에 넣을 키를 확인하고 저에게 전달해 주시는 단계입니다.
1
앱 키 메뉴 이동
해당 앱 클릭 → [앱 설정] → [앱 키]로 이동합니다.
2
JavaScript 키 복사
"JavaScript 키" 항목의 복사 버튼을 눌러 저에게 전달해 주세요.
STEP 5

플랫폼(도메인) 등록

등록된 도메인에서만 지도가 정상적으로 표시됩니다. 이 단계를 빠뜨리면 지도가 안 뜹니다.
1
플랫폼 메뉴 이동
해당 앱 클릭 → [앱 설정] → [플랫폼]으로 이동합니다.
2
Web 플랫폼 등록
"Web 플랫폼 등록"을 클릭하고 실제 홈페이지 도메인 주소를 입력합니다. (예: https://myclinic.co.kr)
⚠️ 도메인 연결(STEP 2)이 먼저 완료되어 있어야 정확한 주소를 입력할 수 있습니다.

STEP 4 · 오시는 길 지도 (네이버)

네이버 지도 API 설정

네이버 지도로도 "오시는 길"을 보여주고 싶을 때 필요한 5가지 단계입니다. 카카오맵과 별개로 등록해야 합니다.

STEP 1

네이버 클라우드 플랫폼 가입 · 로그인

네이버 지도 API는 네이버 클라우드 플랫폼(NCP) 계정으로 발급받습니다.
1
사이트 접속
아래 주소로 접속합니다.
https://www.ncloud.com
2
가입 또는 로그인
네이버 아이디로 가입/로그인하거나, 별도 NCP 계정을 만듭니다. (병원용으로 계속 사용하실 계정 권장)
STEP 2

결제 수단 등록

Application 등록을 위해 카드 등록이 필요합니다.
💡 지도 표시(Web Dynamic Map)는 월 약 1,000만 건까지 무료로 제공됩니다. 병원 홈페이지 수준에서는 이 한도를 넘기기 어려워 실제 과금은 거의 없습니다.
1
결제 수단 등록
마이페이지 → 결제 관리에서 카드 정보를 등록합니다.
STEP 3

Application 등록

지도를 사용할 애플리케이션을 등록하는 단계입니다.
1
Maps 메뉴 이동
콘솔 상단 메뉴에서 Services → Application Services → Maps로 이동합니다.
2
Application 등록
"Application 등록" 버튼을 클릭하고, 병원 이름으로 이름을 입력합니다.
3
서비스 선택 및 도메인 등록
이용할 서비스에서 Web Dynamic Map을 선택하고, 실제 홈페이지 도메인 주소를 등록합니다.
⚠️ 등록한 도메인에서만 지도가 정상적으로 표시됩니다. 도메인 연결(STEP 2)이 먼저 완료되어 있어야 정확히 입력할 수 있습니다.
STEP 4

인증 정보(Client ID) 확인

홈페이지 코드에 넣을 키를 확인하고 저에게 전달해 주시는 단계입니다.
1
인증 정보 보기
등록한 Application 목록에서 방금 만든 앱 이름 아래 "인증 정보" 버튼을 클릭합니다.
2
Client ID 복사
Client ID 값을 복사해서 저에게 전달해 주세요.
💡 "JavaScript 키"라고 부르기도 하지만 정식 명칭은 Client ID입니다. 지도를 띄우는 용도로는 이 값 하나면 충분하고, Client Secret은 필요 없으니 전달하지 않으셔도 됩니다.
STEP 5

Dynamic Map 사용 여부 확인

지도가 정상 작동하려면 이 옵션이 꼭 켜져 있어야 합니다.
1
Application 수정 화면 확인
등록한 Application을 클릭해 수정 화면으로 들어가, Dynamic Map 옵션이 선택되어 있는지 확인합니다.
⚠️ 선택되어 있지 않으면 지도 로딩 시 오류(429)가 발생할 수 있습니다.

업종 · 규모 선택

2

2
웹사이트 URL 입력

💡 도메인 연결(STEP 2)이 아직이라면, 일단 Firebase 기본 주소(예: myclinic-a1b2c.web.app)로 먼저 만들어도 괜찮습니다. 나중에 도메인이 연결되면 자동으로 함께 추적됩니다.

1
스트림 세부정보 확인
생성된 웹 데이터 스트림을 클릭하면 상단에 "측정 ID"가 표시됩니다. (예: G-XXXXXXXXXX)
2
측정 ID 전달
이 측정 ID를 복사해서 저에게 전달해 주세요.

구글 서치콘솔 등록

병원 홈페이지가 구글 검색결과에 정상적으로 노출·색인되도록 등록하는 5가지 단계입니다.

⏱ 예상 소요시간 약 10분
📋 총 5단계
구글 검색결과에 우리 병원이 몇 번 노출되고 클릭됐는지 알려주는 도구예요.
"어떤 검색어로 사람들이 우리 병원을 찾아왔는지" 확인하고, 구글이 사이트를 제대로 읽고 있는지 점검할 때 필요합니다.
구글 애널리틱스(GA4)가 "들어온 이후" 방문자 행동을 본다면, 서치콘솔은 "구글 검색에 얼마나 노출·클릭되는지"를 보여주는 완전히 다른 도구입니다. 등록해두면 어떤 검색어로 병원을 찾아왔는지, 검색 노출에 문제가 없는지 확인할 수 있습니다.

STEP 1

구글 서치콘솔 접속

구글 계정으로 로그인한 상태에서 시작하는 단계입니다.
1
사이트 접속
아래 주소로 접속합니다.
https://search.google.com/search-console
2
시작하기
"시작하기" 버튼을 클릭합니다. (구글 애널리틱스와 같은 구글 계정으로 로그인하시면 편해요)
STEP 2

속성 추가

1
속성 유형 선택
두 가지 방식 중 "URL 접두어"를 선택합니다. (도메인 방식은 DNS 설정이 필요해 더 복잡합니다)
2
사이트 주소 입력
실제 홈페이지 주소(https://로 시작)를 정확히 입력하고 "계속"을 클릭합니다.
STEP 3

소유권 확인 방법 선택

이 사이트가 정말 원장님 소유인지 확인하는 절차입니다.
1
HTML 태그 방식 선택
"다른 확인 방법" → "HTML 태그"를 선택합니다.
2
태그 복사 및 전달
화면에 표시되는 <meta name="google-site-verification" ...> 코드를 복사해서 저에게 전달해 주세요.
💡 구글 애널리틱스(GA4)가 이미 설치되어 있다면, "Google 애널리틱스" 확인 방법을 선택해 태그 없이 바로 인증할 수도 있습니다. 편하신 쪽으로 선택하시면 됩니다.
STEP 4

소유권 확인 완료

전달해 주신 태그를 제가 사이트에 삽입한 뒤 확인하는 단계입니다.
1
태그 삽입 대기
제가 전달받은 태그를 홈페이지에 삽입해 드립니다.
2
확인 버튼 클릭
삽입이 완료됐다고 안내드리면, 서치콘솔 화면에서 "확인" 버튼을 클릭합니다. "소유권이 확인됨" 메시지가 뜨면 완료입니다.
STEP 5

사이트맵 제출

구글이 홈페이지의 모든 페이지를 빠르게 찾아갈 수 있도록 지도를 전달하는 단계입니다.
1
Sitemaps 메뉴 이동
왼쪽 메뉴에서 색인생성 → Sitemaps를 클릭합니다.
2
사이트맵 URL 제출
"새 사이트맵 추가"에 sitemap.xml을 입력하고 "제출"을 클릭합니다. (사이트맵 파일은 제가 미리 만들어 드립니다)
💡 등록 직후에는 데이터가 바로 안 보여요. 검색 실적 데이터는 보통 2~3일, 전체 색인은 수일~수주 걸립니다. 정상적인 과정이니 걱정 안 하셔도 됩니다.

STEP 7 · 검색 노출 관리 (네이버)

네이버 서치어드바이저 등록

네이버 검색결과에도 병원 홈페이지가 노출되도록 등록하는 5가지 단계입니다. 구글 서치콘솔과 역할은 같지만 등록은 별개입니다.

⏱ 예상 소요시간 약 10분

국내는 네이버 검색 비중이 높아서, 네이버에서도 우리 병원이 검색되게 하려면 꼭 등록해야 합니다.
국내에서는 지역 병원 검색 시 네이버 비중이 특히 높아 구글 서치콘솔 못지않게 중요합니다. 등록 후 실제 검색 노출까지는 보통 1~4주 정도 걸립니다.

소유 확인 방법 선택

HTML 태그 방식 선택

1

⚠️ HTML 태그 방식은 1년마다 재인증이 필요합니다. 만료 안내가 오면 다시 확인해 주세요.
